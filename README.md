## 📚 What is Matplotlib?

**Matplotlib** is a comprehensive plotting library for Python. It enables the creation of static, animated, and interactive visualizations, offering a wide variety of plot types. Matplotlib is highly customizable, which makes it suitable for both simple and complex data visualization tasks.

---

## ✨ Features

- **Create a wide variety of plots**: Line, bar, scatter, histograms, and more.
- **Customizable styles**: Control plot aesthetics such as colors, labels, and legends.
- **Integration**: Works seamlessly with NumPy and Pandas.
- **Output formats**: Save plots in different formats such as PNG, SVG, and PDF.
